# super-store-sales-dashboard
Project Overview

The Super Store Sales Dashboard is an interactive Power BI dashboard that provides a comprehensive analysis of sales performance, profit, customer segments, payment modes, shipping methods, and regional sales distribution. It enables businesses to monitor key performance indicators (KPIs) and make data-driven decisions through interactive visualizations.

🚀 Features
Interactive Region Slicer (Central, East, South, West)
KPI Cards displaying:
Total Sales
Total Profit
Total Quantity Sold
Average Delivery Time
Sales Analysis by:
Category
Sub-Category
Customer Segment
Payment Mode
Ship Mode
Monthly Sales and Profit Trend Analysis
Geographic Sales Distribution using Map Visualization
Interactive filtering for quick business insights
